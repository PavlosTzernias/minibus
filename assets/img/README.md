# Фάκελος Φωτογραφιών Οχήματος / Vehicle Images Directory

Εδώ τοποθετούνται οι πραγματικές φωτογραφίες του Mini Bus σε μορφή `.webp` (ή `.jpg`/`.png`).
Όταν είναι έτοιμες, απλώς αντικαθιστάτε τα paths στο `js/data/fleet.js`:
- `sprinter-hero.webp`
- `sprinter-exterior.webp`
- `sprinter-interior.webp`
- `sprinter-luggage.webp`
